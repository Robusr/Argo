# Hardware 模块说明文档
## 模块概述
本模块负责 Argo 船设计项目的硬件与嵌入式开发工作，涵盖 STM32 主控制核心、树莓派辅助控制、PCB 电路设计三大部分，实现船舰的电机控制、传感器数据采集、与上位机通信等功能，是船舰运行的硬件基础。

## 环境配置
### 1. STM32 开发环境
- 软件安装：安装 STM32CubeMX（用于工程配置）、MDK-ARM（用于代码编译、下载）
- 驱动安装：安装 ST-Link 驱动（用于程序下载），确保电脑能识别 ST-Link 设备
- 工程配置：打开 `Firmware/STM32/MDK-ARM` 目录下的工程文件（.uvprojx），确认编译器版本、芯片型号配置正确

### 2. 树莓派开发环境
- 系统配置：树莓派安装 Raspberry Pi OS（推荐32位版本），开启串口、SPI等外设
- 开发工具：可通过 SSH 远程连接树莓派开发，或使用 VS Code 远程开发插件
- 依赖安装：进入 `Firmware/RaspberryPi` 目录，执行 `pip install -r requirements.txt` 安装所需依赖

### 3. PCB 设计环境
- 软件安装：安装 Altium Designer 或 KiCad（根据项目使用工具选择）
- 元件库配置：将 `PCB/libraries` 目录下的元件库导入设计软件，确保元件库可用

## 运行步骤
### 1. STM32 固件运行
1. 打开 MDK-ARM 工程，加载 `Firmware/STM32/MDK-ARM` 下的工程文件
2. 根据需求修改代码（如控制逻辑、通信参数），编译代码（无报错）
3. 将 ST-Link 连接到 STM32 开发板和电脑，点击下载按钮，将固件下载到开发板
4. 下载完成后，复位开发板，固件开始运行，可通过串口查看运行日志

### 2. 树莓派代码运行
1. 将树莓派与电脑或硬件设备连接（串口、网络）
2. 远程连接树莓派，进入 `Firmware/RaspberryPi/scripts` 目录
3. 执行运行脚本：`python run_main.py`，启动树莓派程序
4. 程序运行后，可通过日志查看传感器数据采集、通信状态等信息

### 3. PCB 设计与生产
1. 打开 PCB 设计软件，加载 `PCB/project` 目录下的工程文件
2. 根据 `docs` 目录下的设计说明，完善原理图和 PCB 布局
3. 设计完成后，生成 Gerber 文件，保存至 `PCB/gerber` 目录
4. 参考 `BOM.xlsx` 物料清单采购元器件，将 Gerber 文件提交给厂家进行 PCB 打样
5. 打样完成后，根据 `wiring_diagram.pdf` 接线图进行元器件焊接和接线

## 注意事项
1. STM32 代码开发需遵循 DEV_SPEC.md 中的 C/C++ 代码风格规范，函数、变量命名符合要求，添加必要注释
2. 树莓派代码需遵循 Python 代码风格规范，配置文件统一存入 `config` 目录
3. PCB 设计需遵循电气规范，布局合理，避免干扰，确保焊接和使用安全
4. BOM.xlsx 需准确完整，元器件型号、数量、封装需与设计一致，避免采购错误
5. 芯片手册、原理图等文档需及时更新，存入 `docs` 目录，便于查阅
6. 禁止提交编译产物（.hex、.bin）、临时文件、PCB 设计过程文件，需在 `.gitignore` 中配置忽略
7. 硬件接线时需注意正负极，避免短路损坏设备

## 常见问题
1. STM32 程序下载失败：检查 ST-Link 驱动是否安装、连接是否正常，芯片型号配置是否正确
2. 树莓派无法读取传感器数据：检查传感器接线是否正确，引脚配置是否与代码一致
3. PCB 设计报错：检查元件库是否导入，原理图是否存在短路、虚焊等问题
4. 串口通信失败：检查通信参数（波特率、引脚）是否一致，接线是否正确
