# Software 模块说明文档
## 模块概述
本模块负责 Argo 船设计项目的 PC 端上位机软件开发，主要实现与嵌入式硬件（STM32、树莓派）的通信、传感器数据接收与解析、数据可视化、参数配置、指令下发等功能，为船舰的调试和控制提供可视化操作界面。

## 目录结构
```
Software/
├── README.md                 # 本文档
├── src/                      # 源代码目录

│   ├── ui/                   # 用户界面模块（界面布局、控件逻辑）
│   ├── communication/        # 通信模块（串口/网络通信，与硬件交互）
│   ├── data_processing/      # 数据处理模块（传感器数据解析、滤波）
│   ├── visualization/        # 可视化模块（数据图表、船体状态显示）
│   ├── config/               # 配置文件（通信参数、显示参数等）
│   └── utils/                # 工具类（日志记录、异常处理、文件操作）
├── tests/                    # 单元测试（各模块功能测试、接口测试）
├── resources/                # 资源文件
│   ├── icons/                # 图标资源（程序图标、控件图标）
│   ├── images/               # 图片资源（背景图、船体示意图）
│   ├── fonts/                # 字体资源（界面显示字体）
```

## 环境配置
### 1. 软件安装
- Python：建议安装 3.8~3.10 版本（兼容性最佳）
- 开发工具：建议使用 PyCharm（推荐）或 VS Code，安装 Python 插件

### 2. 依赖安装步骤
1. 克隆仓库后，进入 `Software` 目录
2. 打开命令行，执行以下命令安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 确认依赖安装成功（无报错），若出现版本冲突，可根据提示调整对应依赖版本

### 3. 配置文件设置
1. 进入 `src/config` 目录，修改 `config.ini` 文件中的通信参数（波特率、串口端口、IP地址等），确保与硬件参数一致
2. 根据需求调整 `display_config.ini` 文件中的显示参数（图表刷新频率、数据显示格式等）

## 运行步骤
### 1. 开发环境运行
1. 打开 PyCharm/VS Code，加载 `Software` 目录下的项目
2. 定位到 `src/main/main.py` 文件，点击运行按钮，启动上位机软件
3. 软件启动后，选择通信方式（串口/网络），配置对应参数，点击“连接”按钮，与硬件建立通信
4. 通信成功后，即可实现数据接收、可视化、指令下发等功能

### 2. 打包运行（生成可执行文件）
1. 进入 `Software` 目录，打开命令行
2. 执行打包脚本：
   ```bash
   python setup.py build
   ```
3. 打包完成后，在 `build` 目录下生成可执行文件，双击即可运行（无需安装Python环境）
4. 若需生成安装包，可执行：
   ```bash
   python setup.py bdist_msi
   ```

## 功能说明
1. 通信功能：支持串口、网络两种通信方式，可自动识别串口设备，支持参数动态配置
2. 数据处理：接收硬件发送的传感器数据（如速度、姿态、位置等），进行解析、滤波和存储
3. 可视化功能：通过折线图、仪表盘、指示灯等形式，实时显示船舰状态数据，支持数据回溯
4. 指令下发：向硬件发送控制指令（如电机启停、速度调节、路径规划指令等）
5. 数据导出：支持将接收的历史数据导出为 CSV 格式，便于后续分析
6. 日志记录：自动记录软件运行日志和通信日志，便于问题排查

## 注意事项
1. 代码开发需遵循 DEV_SPEC.md 中的 Python 代码风格规范，命名、注释符合要求
2. 新增功能时，需同步编写单元测试代码，存入 `tests` 目录，确保功能可用
3. 资源文件（图标、图片）需按类型存入 `resources` 对应子目录，命名规范
4. 依赖包版本需严格遵循 `requirements.txt` 中的定义，避免版本冲突导致软件无法运行
5. 禁止提交编译产物、临时文件、虚拟环境目录，需在 `.gitignore` 中配置忽略
6. 软件修改后，需同步更新 `docs` 目录下的用户手册和开发文档

## 常见问题
1. 软件无法启动：检查 Python 版本和依赖包是否安装正确，查看运行日志排查错误
2. 无法与硬件建立通信：检查通信参数（波特率、端口）是否与硬件一致，确认硬件正常工作
3. 数据显示异常：检查数据解析逻辑是否正确，确认硬件发送的数据格式符合约定
4. 打包失败：检查 setup.py 配置是否正确，确保所有依赖包已安装
